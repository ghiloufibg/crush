Fetch a Kubernetes pod's recent logs via `kubectl logs`. Returns at most tail_lines of the most recent output (default 200, hard-capped at 500 regardless of what's requested) since pod logs can be very large. Use grep to narrow results to lines containing a specific substring, e.g. when looking for an error or a specific request ID, instead of requesting more lines. This is a one-shot snapshot, not a live stream.
